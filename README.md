# StudioVela49 — nuovo sito (in lavorazione)

Rifacimento del sito di **StudioVela49 — Ing. Natale Lombardo** (Torino): certificazioni energetiche (APE), diagnosi energetiche, impianti solari, bonus e detrazioni, amministratori di condominio, prevenzione incendi.
Sito attuale: https://www.studiovela49.it (del 2012). Anteprima futura: https://griveljoseph3-ship-it.github.io/studiovela49/

## Da dove partire
1. **`docs/PROMPT-CLAUDE.md`**: il messaggio da incollare in Claude Code per costruire il sito.
2. **`docs/PIANO-CLAUDE.md`**: il piano completo (pagine, design, conversione, SEO, qualità, extra da proporre dopo).
3. **`materiale/`**: testi e dati veri del sito attuale, foto originali, foto libere Pexels con crediti, screenshot del "prima".

## Struttura
```
docs/                         piano e prompt per Claude
materiale/contenuti-sito-attuale.md   tutti i testi e dati estratti dal sito attuale
materiale/foto-originali/     foto del sito attuale (max 300×330 px) + LEGGIMI.md
materiale/foto-libere/        14 foto Pexels 2400 px + CREDITI.md
materiale/documenti/          PDF informativo del cliente
materiale/screenshot-sito-attuale/    come è il sito oggi
(radice)                      sito base di Joseph, da adattare (vedi README-SITO-BASE.md)
```

Il sito base contiene ancora l'esempio inventato "Maison Aurore": verrà sostituito da Claude seguendo il piano.
